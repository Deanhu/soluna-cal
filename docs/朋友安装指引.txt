SolunaCal 卸载重装指引（照着做就行）
=====================================

你现在的情况：屏幕上那个提示「不能将 SolunaCal 移到废纸篓，因为它已打开」，
意思是程序正在后台运行，系统不允许删除运行中的程序。先退出，再删，再装新版。

全程大概 3 分钟。每一步都写清楚你会看到什么。


第 0 步　关掉当前提示
---------------------
点提示框里的「好」。


第 1 步　把正在运行的 SolunaCal 退掉
-----------------------------------
推荐用「活动监视器」，不需要打命令：

  1) 按 Command + 空格，弹出搜索框
  2) 输入「活动监视器」，回车
  3) 窗口右上角有个搜索框，输入 SolunaCal
  4) 列表里选中 SolunaCal
  5) 点窗口左上角的 ⓧ 按钮
  6) 弹窗里选「强制退出」

注意：Command + Option + Esc 弹的那个「强制退出」窗口通常列不出 SolunaCal，
      因为这个程序没有 Dock 图标，属于菜单栏配件。所以走活动监视器这条路。

如果你更愿意用命令，也行（效果一样）：
  1) Command + 空格 → 输入「终端」→ 回车
  2) 复制下面这一行，粘贴进去，回车：

     pkill -x SolunaCal; sleep 1; pgrep -x SolunaCal || echo "已退出"

  3) 看到「已退出」就成功了；没有输出也没有报错，同样算成功。


第 2 步　确认真的退出了
-----------------------
回到活动监视器，搜索框里再输一次 SolunaCal：
搜不到任何东西 = 已经退出了，可以往下走。
还能搜到 = 回到第 1 步再退一次。


第 3 步　删掉旧版本
-------------------
  1) 打开「访达」（Dock 最左边那个笑脸图标）
  2) 按 Shift + Command + A，打开「应用程序」文件夹
  3) 找到 SolunaCal，按住拖到废纸篓
  4) 如果系统要密码，输入你的开机密码

这一步应该不会再报「已打开」了。如果还报，说明第 1 步没退干净。


第 4 步　安装 0.2.2
-------------------
  1) 双击 SolunaCal-0.2.2.dmg（你收到的那个磁盘文件）
  2) 在打开的窗口里，把 SolunaCal 图标拖到右边的「Applications（应用程序）」文件夹
     —— 一定要先拖过去，别在这个窗口里直接双击它
  3) Command + 空格 → 输入「终端」→ 回车
  4) 复制下面这一行，整行粘贴进去，回车：

     xattr -cr /Applications/SolunaCal.app

     （可能要输开机密码；输的时候屏幕上不显示字，输完直接回车）

  5) 打开「启动台」，找到 SolunaCal，双击
  6) 装好后在访达左边把 SolunaCal 这个磁盘点「推出」

为什么要第 4 步那行命令：这个软件没有 Apple 的付费开发者签名（一年 99 美元），
系统给下载来的文件打了隔离标记就不认它。这行命令是清掉那个标记，
不改任何系统设置，也不影响别的软件。


第 5 步　确认装好了
-------------------
打开后，看屏幕右上角（菜单栏）：应该出现一个圆形月牙图标 + 「10月20日 周二」这样的日期。

第一次打开还会弹一个「欢迎使用 Soluna」的窗口，看完点完成。
它不会出现在 Dock 里，这是正常的——菜单栏工具都这样。

如果这两样都看到了，就装好了，可以直接用：点右上角的日期，展开整月日历。


第 6 步　如果右上角还是什么都没有
---------------------------------
先判断：是不是菜单栏太挤。刘海屏 Mac 上，放不下的项会被系统藏到刘海后面，
不显示也不提示。

切成「仅图标」试试（宽度从约 120pt 降到约 22pt）：

  · 能打开弹窗的话：点菜单栏日期 → 齿轮「设置」→「菜单栏形态」改成「仅图标」
  · 打不开弹窗（因为根本看不到图标）：终端里粘贴这三行

      defaults write com.soluna.cal statusItemStyle -int 2
      pkill -x SolunaCal; sleep 1
      open /Applications/SolunaCal.app

其他办法：退出几个别的菜单栏 App 腾位置，或把鼠标移到屏幕顶部等一秒。

还是不行，再跑自检：

  /Applications/SolunaCal.app/Contents/MacOS/SolunaCal --selfcheck

它会打印七段检查结果，最后给一句结论。把整段内容截图发回来即可，
上面会直接写清楚卡在哪：没装对 / 还被系统拦着 / 菜单栏项建不出来。

自检结果怎么看：
  ✗ 正在从磁盘映像（DMG）里运行   → 没真正装到「应用程序」
  ✗ 仍有 com.apple.quarantine      → 第 4 步那行命令没生效
  ✗ 缺少 LunarCore.framework       → 拷贝不完整，重装
  ✗ 菜单栏项创建失败               → 程序 bug，把输出发回
  全部 ✓ 但还是看不到              → 菜单栏空间问题，用上面切「仅图标」的办法


第 7 步　以后想退出或卸载
-------------------------
退出（三个办法，任选）：
  · 点菜单栏上的日期 → 点齿轮「设置」→ 拉到最下面 → 「退出 SolunaCal」
  · 右键点菜单栏上的 SolunaCal 图标 → 「退出 SolunaCal」
  · 活动监视器里搜 SolunaCal → ⓧ 强制退出

卸载：
  退出之后，把「应用程序」里的 SolunaCal 拖进废纸篓即可。

想连日志一起清掉（可选）：删掉 ~/Library/Logs/SolunaCal.log
方法：访达里按 Shift + Command + G，粘贴 ~/Library/Logs ，回车，找到 SolunaCal.log 删掉。


常见提示对照
------------
「Apple 无法验证 SolunaCal…」   → 第 4 步那行 xattr 命令没做，或者路径写错了
「已损坏，无法打开」             → 同上
「不能移到废纸篓，因为它已打开」 → 第 1 步没退出
Dock 里没有图标                  → 正常，它只在菜单栏
