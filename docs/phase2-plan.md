# SolunaCal 二期（V2 · 离不开）技术规划

> 2026-10-15 定稿。对应 PRD：outputs/2026-10-15-calendar-prd-2phase.html。
> 产品回顾结论：范围零调整；3 条执行级修正见文末。

## 实施顺序（按依赖与风险，非 PRD 列表序）

### 1. 菜单栏格式 token 拼装
- **格式化引擎**（LunarCore，纯函数）：`MenuBarFormat.render(template:date:)`
  - token 集：`{Y} {M} {D} {W}`（公历年/月/日/周）、`{LM} {LD}`（农历月/日，闰月自动带「闰」）、`{GY}`（年干支）、`{SX}`（生肖）
  - 非法 token 兜底：未知 `{X}` 原样保留渲染（不崩、不空白）；空模板回退默认
- **预设 3 档**：`10月15日 周四` / `10月15日 周四 · 九月初六` / `九月初六 · 丙午年`
- **一期开关迁移**：`menuBarLunar=true` 等价于预设 2；开关保留，改预设时开关跟随
- **编辑器**：设置页文本框 + 实时预览 + 可用 token 说明 + **长度预警**（预估宽度超阈值时黄字提示「刘海屏可能显示不全」）
- 验收映射：编辑器实时预览 ✓ / 预设 3 档 ✓ / 非法 token 兜底 ✓ / 长度预警（新增）

### 2. 快捷键呼出 + 悬停弹出
- 全局快捷键：Carbon `RegisterEventHotKey`（无需辅助功能权限；NSEvent 全局监听无法拦截按键）
- 默认 ⌥C；设置页录制框（本地监听按键捕获）；冲突处理：注册失败提示换键
- 悬停：statusItem button 加 trackingArea，mouseEntered → 延迟（默认 0.4s，0.2–1.5s 可调，可关）→ 开弹窗；mouseExited 取消
- 验收映射：全局快捷键可自定义 ✓ / 悬停延迟可调可关 ✓

### 3. 通知能力（节日/放假/生日提醒）
- UNUserNotificationCenter；LSUIElement App 直接可用
- 三类独立开关：放假提醒（假期前一日 18:00「明天开始休 N 天」）、节日提醒（当日 09:00）、生日提醒（当日 09:00，数据源 = BirthdayStore.nextOccurrence）
- 免打扰时段：开始/结束时间两个 time picker，命中则顺延到时段结束
- 调度策略：App 启动时重排未来 60 天通知（定时器幂等重排，不依赖后台唤醒）
- 验收映射：系统原生通知 ✓ / 每类独立开关 ✓ / 免打扰时段 ✓

### 4. 皮肤系统 + 春节限定皮肤
- 一期颜色已全部 token 化（Color.adaptive）；皮肤 = 一组 token 覆盖层：`Skin` 枚举（default / springFestival）注入环境值
- 春节皮肤：色带/角标/节日红换春联红色系（朱砂 #9E2B22 系）；**不动布局、不动密度**
- 限时上架逻辑：皮肤常年可选，「春节限定」仅指营销位；默认皮肤不变
- 验收映射：纯 token 包不改布局 ✓

### 5. 双击日期创建事件
- 双击日期格 → 格内就地编辑条（单行文本 + 回车确认 / Esc 取消）
- 写入走 EKEventStore.save；失败 toast（无权限/冲突）
- 授权：macOS 14 fullAccess 已涵盖读写；Info.plist 文案需从「读取」改为「读取与写入」
- 验收映射：就地编辑条 ✓ / EventKit 写入 ✓ / 失败明确提示 ✓

### 6. 真太阳时 / 干支 / 时辰显示
- 时辰：时干支 = 五鼠遁（日干推时干）；日干支 = 儒略日推算（查表外算法，需锚点验证）
- 真太阳时 = 平太阳时 + 均时差（天文近似式）+ 经度修正（相对东经 120°）
- 定位：CoreLocation 一次定位缓存经纬度；拒绝授权则回退「按北京时间（东经 120°）」并明示
- 默认关；显示位 = 弹窗选中日的详情区
- 验收映射：按系统定位校正 ✓ / 默认关 ✓

### 7. macOS 小组件
- WidgetKit 大/中两尺寸；月历渲染组件从 SolunaUI 抽出共享
- 数据共享：App Group（`group.com.soluna.cal`）——**真机验收依赖付费开发者证书签名**，ad-hoc 阶段用模拟器验收
- 验收映射：大/中两尺寸 ✓ / 与弹窗同源渲染 ✓

## 执行级修正（产品回顾产出，PRD 未写）
1. token 编辑器必须带长度预警（刘海屏实测：超长状态项被系统静默隐藏）
2. 一期「菜单栏显示农历」开关由 token 预设吸收，不允许两套格式逻辑并存
3. 小组件真机验收 = 上架签名阶段的前置依赖，列入里程碑风险

## 全局约束（沿用一期纪律）
- 历法/节日事实断言必须先独立核对再写进测试
- 新增 Swift 文件后必须重跑 xcodegen generate
- 每功能：纯逻辑抽纯函数 → 测试锁 → RenderHarness 离屏渲染 → Release 重打包签名
