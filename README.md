# SolunaCal

## 抬头看时间，也看懂今天。

给中国用户的 macOS 菜单栏日历。

公历、农历、节气、节日、调休、生日和日程，常驻在你每天都会看到的菜单栏里。点一下，三秒看清今天；不用为了查一个农历日期，专门打开网页或完整日历 App。

> 这是一个自研、无广告、无需登录的 macOS 工具。

## 为什么安装 SolunaCal？

macOS 默认告诉你现在几点，但它不一定告诉你：

- 今天对应的农历是什么；
- 今天是不是节气或传统节日；
- 什么时候放假、哪天补班；
- 离重要的生日和纪念日还有多久；
- 今天是否已经有需要处理的日程。

SolunaCal 把这些中国用户每天都会用到的信息，放回系统时间旁边。你抬头看时间时，也能顺手看懂今天。

## 它能帮你做什么？

| 你想做什么 | SolunaCal 怎么帮你 |
| --- | --- |
| 看今天是什么日子 | 公历、农历、星期、节气和节日一眼显示 |
| 确认什么时候放假 | 连续假期用色带表达，休息日与补班日清楚区分 |
| 不想忘记生日和纪念日 | 支持公历/农历日期、每年/每月重复和倒计时 |
| 查看已有安排 | 读取系统日历中的可编辑日程；订阅节日、节气等只读内容不会混进日程列表 |
| 想快速新增安排 | 双击日期打开日程编辑；有系统权限时写入系统日历，没有权限时仍可保存在本机 |
| 看完其他月份想回来 | 「回到今天」同时恢复当前月份和今天的选中状态 |
| 需要换一种显示方式 | 支持菜单栏格式、是否显示农历、弹窗密度、深浅色外观等设置 |

## 你每天会遇到的几个场景

### 看时间时，顺便知道今天

不用打开手机，也不用搜索“今天农历几号”。菜单栏就是你的低打扰入口。

### 安排工作时，快速确认假期

休息日、补班日和连续假期被分开表达，避免只看颜色或只看一个日期造成误判。

### 记住家人的生日和重要日子

公历和农历都能记录。生日、纪念日会和当天的日历信息放在同一个入口里。

### 把个人安排和中国日期放在一起

系统日历里的日程可以和公历、农历、节气、节日一起查看；订阅日历中的重复节气和只读节日不会被误当成可以删除的个人日程。

## 核心功能

- **菜单栏常驻**：不占 Dock 位置，点开即可查看月历。
- **公历与农历**：月历展示公历日期、农历日期和星期信息。
- **节气与节日**：节气、传统节日和公历节日以文字表达，不靠用户猜颜色。
- **节假日与调休**：连续休息日用色带连接，休息日与补班日采用清晰的视觉语义。
- **生日与纪念日**：支持公历/农历、每年/每月重复、倒计时和提醒设置。
- **系统日程**：可读取、创建和删除系统日历中的可编辑事件；重复事件只删除本次。
- **本机日程兜底**：没有系统日历权限时，新建日程仍可保存到本机，不会因为权限失败而丢失输入。
- **菜单栏与弹窗设置**：可调整菜单栏格式、农历显示、弹窗密度和外观。
- **Widget 与引导**：提供菜单栏工具形态、首次使用引导和桌面 Widget 支持。

## 我们的产品原则

SolunaCal 不只是把一张农历表放进菜单栏，也尽量把边界讲清楚：

- **公共日期和个人日程分开**：节日、节气不伪装成用户自己的日程。
- **只读内容不提供假删除按钮**：订阅节假日、节气和生日日历不会混入可编辑列表。
- **没有权限也不让用户白填**：系统日历权限不足时，日程可以落到本机保存。
- **每个动作都给反馈**：授权失败会告诉你去哪里处理，删除失败会显示具体原因。
- **事实要能复核**：历法测试中的节气、农历和干支事实使用独立方法核对，不靠猜测让测试“通过”。

## 下载与安装

从 [Releases](https://github.com/Deanhu/soluna-cal/releases) 下载最新的 DMG 安装包。

1. 打开 DMG，将 `SolunaCal.app` 拖到「应用程序」文件夹。
2. 从「应用程序」文件夹启动 SolunaCal。
3. 如果 macOS 第一次阻止打开，按安装包中的说明操作；这是未使用 Apple 付费开发者签名时的系统安全提示，不代表应用文件损坏。
4. 如果需要读取或写入系统日历，在详情卡中点击「授权」。没有授权时，新增日程仍可保存到本机。

## 当前状态

- 支持 macOS 14.0 及以上。
- 提供 Apple Silicon 与 Intel 双架构构建。
- 历法数据覆盖 1900–2099。
- 节假日数据采用在线主源、本地缓存、内置兜底三级策略。
- 当前版本的完整测试由 Xcode 项目执行，覆盖历法换算、节气、干支、节日、调休、倒计时、生日、日程和弹窗规则。

## 构建与测试

```bash
# 重新生成 Xcode 工程（project.yml 是工程真源）
xcodegen generate

# 编译
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project SolunaCal.xcodeproj -scheme SolunaCal -configuration Release build

# 单元测试
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild test -project SolunaCal.xcodeproj -scheme SolunaCal
```

本机 Swift Package 的 `swift test` / `swift build` 可能被嵌套沙箱拦截，因此项目验收统一以 Xcode 项目测试为准。

## 出包

```bash
tools/make_dmg.sh
```

脚本会执行前置检查、生成双架构 Release App、进行 ad-hoc 签名、运行冒烟测试并生成 DMG 安装包。前置检查包括：

- 历法事实断言来源守卫；
- 节气断言独立对账；
- Xcode 单元测试。

## 项目结构

```text
Sources/LunarCore/          历法引擎与日历数据层（纯 Swift）
  LunarCalendar.swift       农历换算 / 节气 / 干支生肖
  Festivals.swift           节日表 + 调休数据层
  Generated/LunarData.swift 数据表（机械生成，勿手改）
Sources/SolunaCal/          菜单栏 App（SwiftUI + AppKit）
Sources/SolunaUI/           月历、设置、生日、日程等界面
Tests/LunarCoreTests/       单元测试
```

## 数据口径

- 历法数据：内置数据表，覆盖 1900–2099。
- 调休数据：在线主源 → 本地缓存 → 内置兜底三级；另有校验源对账。
- UI 语义：今日唯一实心高亮、假期色带整段单角标、红休灰班、节日节气文字表达。
